# نظام إدارة العيادات الطبية 🩺

نظام متكامل لإدارة عيادة طبيب — **Django REST Framework** (باك-إند) + **React 19 / TypeScript / Ant Design** (فرونت-إند).

> نسخة عامة لأي تخصص طبي، مشتقة من نظام عيادات الأسنان بعد إزالة الوحدات الخاصة بالأسنان (مخطط الأسنان، التقويم، معامل التركيبات).

## الوحدات المُنفَّذة

- 🔐 تسجيل دخول JWT بأدوار + نظام صلاحيات (الحذف للمدير فقط في الوحدات الحساسة)
- 👨‍⚕️ إدارة المرضى + الملف الطبي (تاريخ مرضي، حساسية، أمراض مزمنة)
- 📅 نظام مواعيد مع منع تعارض حجز نفس الطبيب + ربط بالفرع
- 📋 السجل الطبي (EMR): شكوى + تشخيص + علاج + تكلفة
- 📝 خطط العلاج متعددة البنود مع تتبع التنفيذ ونسبة الإنجاز
- 🗂️ قوالب خطط علاج ثابتة تُدار من الإعدادات ويستدعيها الطبيب داخل ملف المريض
- 🧾 الفوترة الجزئية لخطة العلاج: علامة ✔ على البند تضيفه لفاتورة الخطة تلقائياً
- 📑 الروشتة الإلكترونية + طباعة / PDF + قائمة أدوية بتعبئة تلقائية
- 💰 الفواتير + الدفعات + الأقساط + طباعة / PDF
- 📦 المخازن والموردون (أصناف، حركات وارد/منصرف، حد إعادة الطلب)
- 📂 مرفقات المريض (أشعة/صور/تحاليل/مستندات)
- 🏥 الفروع المتعددة + إدارة المستخدمين والأطباء من الإعدادات
- 🔔 تنبيهات فورية (مواعيد اليوم، أقساط متأخرة/مستحقة، نقص مخزون)
- 🩺 نظام الكشف والاستشارة: نوع الزيارة (كشف/إعادة/استشارة/إجراء) برسوم قابلة للتعديل — زر "تحصيل"
- ⚙️ التحكم في أنواع الزيارات وأسعارها من الإعدادات
- 🏥 شاشة استقبال (Reception) + غرفة انتظار بترتيب ذكي (نداء/تقديم/تأخير/إنهاء)
- 📊 لوحة تحكم بفلتر تاريخ (من/إلى): كل الأرقام والجرافات تتغير حسب الفترة + جراف إيرادات خطي منحني
- 📑 مركز تقارير: تقرير مريض، تقرير طبيب، بيان يومي — كلها بفترة زمنية وطباعة PDF
- 💼 حساب العيادة: مصروفات بالفئات + مدفوعات الموردين + صافي ربح/خسارة بفترة
- 📱 تذكيرات واتساب + قوالب رسائل قابلة للتعديل + شعار العيادة في الطباعة
- 🤖 شات بوت واتساب للحجز الذاتي (Meta Cloud API): العميل يحجز بمحادثة والحجز يظهر في النظام بمصدر "واتساب"
- 🌐 دعم كامل للعربية والإنجليزية مع مبدّل لغة (RTL/LTR)
- 🎨 واجهة احترافية بثيم أزرق طبي: نافبار علوي أفقي متدرّج + شعار درع طبي

## التشغيل

### الباك-إند
```bash
cd backend
source venv/bin/activate
python manage.py migrate
python manage.py seed_demo      # بيانات تجريبية
python manage.py runserver 127.0.0.1:8011
```

### الفرونت-إند
```bash
cd frontend
npm install
npm run dev                     # http://localhost:5174
```

## بيانات الدخول التجريبية
- المدير: `admin` / `admin123`
- الأطباء: `dr.ahmed` أو `dr.mona` / `pass1234`
- الاستقبال: `reception` / (بلا كلمة مرور — عيّنها من لوحة الأدمن)

## بنية المشروع
```
backend/
  config/            إعدادات + urls + dashboard/notifications/reports + permissions
  apps/
    users/           المستخدمون + JWT + أدوار + فرع
    clinic/          الفروع + أنواع الزيارات + إعدادات العيادة والواتساب
    patients/        المرضى + الملف الطبي
    appointments/    المواعيد (+ فرع + مصدر الحجز + غرفة الانتظار)
    records/         السجل الطبي (EMR) + خطط العلاج + قوالب الخطط
    billing/         الفواتير + الدفعات + الأقساط
    prescriptions/   الروشتات + قائمة الأدوية
    files/           مرفقات المرضى
    inventory/       المخازن والموردون وحركات المخزون
    finance/         المصروفات وملخص حساب العيادة
    chatbot/         بوت حجز واتساب (webhook + محادثة بخطوات)
frontend/
  src/
    app/             store + RTK Query api + authSlice
    components/      AppLayout, ClinicLogo, RowActions, PatientSelect
    components/patient/  PlansTab, PrescriptionsTab, FilesTab, InvoicesTab
    pages/           Login, Dashboard, Reception, WaitingRoom, Patients, PatientDetail,
                     Appointments, Invoices, Finance, Inventory, Reports, Settings
    i18n.tsx         نظام الترجمة (عربي/إنجليزي) + مبدّل اللغة
```

ملاحظة: البورتات هنا 8011 (باك) و5174 (فرونت) حتى يعمل النظام جنباً إلى جنب مع نسخة عيادة الأسنان (8010/5173).
